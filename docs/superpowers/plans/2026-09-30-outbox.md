# Step 9: Transactional Outbox — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every `SystemEvent` is written to `outbox_events` in the same PostgreSQL transaction as its state change. SSE is fed by `LISTEN outbox`. Webhook alerts reach Matrix through lease-claimed `outbox_deliveries`. `EventBroadcaster`, `webhook_outbox` and the old background-worker mechanism are deleted.

**Architecture:**
- **Domain.** `domain/events.rs` holds the event enum and pure delivery rules.
- **Repository.** `infrastructure/postgres/repositories/outbox.rs` holds every outbox query.
- **Application.** `application/outbox/OutboxService` serves the runtime, and every feature service publishes inside its own transaction.
- **Runtime.** `backend/src/events/` is a SQL-free runtime (listener, SSE hub, dispatcher, purge), spawned by `app.rs` next to the job runtime.
- **Sink.** `interface/events/matrix_room.rs` is the only Matrix-aware part.

**Tech Stack:** Rust, sqlx 0.9 (`query!` macros, `PgListener`), PostgreSQL 18, tokio (`mpsc`, `Notify`, `CancellationToken`), axum SSE, matrix-sdk 0.18.

**Spec:** `docs/superpowers/specs/2026-09-30-outbox-design.md`. Read it first; this plan argues from it. Also read `AGENTS.md` and `docs/superpowers/HANDOFF.md` §5, §6 and §8.

**Worktree:** `D:\01_Data\code\matrix-hello-bot-outbox`, branch `refactor/outbox`. Never work in the main checkout.

## Global Constraints

- **Frozen contracts.** `backend/openapi.json` must be byte-identical after every task. The SSE wire format is `{"type": "<VariantName>", "payload": …}` with unchanged variant names. No chat command or reply changes.
- **SQL.** Only `sqlx::query!` / `query_as!` / `query_scalar!`; never format a value into SQL text. Regenerate `.sqlx/` whenever a query changes and commit it.
- **Migrations** are forward-only files, LF line endings, and never edited once committed.
- **Layers.** No SQL in `interface/`, `application/`, `jobs/` or `events/` production code. `events/` also has no SQL in its tests and no `crate::interface`, `axum`, `matrix_sdk`, `reqwest` or `utoipa` imports.
- **File size.** No file in `backend/src/` exceeds 500 production lines (`#[cfg(test)]` excluded).
- **Error handling.** No `unwrap()`/`expect()` on runtime paths. Every long-lived task gets a child `CancellationToken` and joins `app::run`'s shutdown.
- **Hard safety rules** (HANDOFF §6): never read `.env` or `data/` of the main checkout, never run the bot binary (only `cargo run --bin generate-openapi`), never push/merge/PR, never bare `git stash`.
- **Commits.** Conventional Commits, one logical change each. End every message with the committing model's trailer (R41), e.g. `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- **Execution split** (user directive): Sonnet subagents implement, debug and commit. Opus reviews each task's diff `BASE..HEAD` against the spec and this plan, and runs the final verification.

## Plan clarifications (supersede the spec text where they differ; record in HANDOFF as R53)

- **C1 — frozen webhook counters.** `webhooks.failure_count` goes up on **every** failed attempt (retry or final), exactly as `mark_outbox_retry` and `mark_outbox_failed` do today; `total_delivered_count` goes up on delivery. `enqueue_alert` also stamps `webhooks.last_triggered_at` in the same transaction as the publish. The spec §5.3 wording ("`failure_count` on failed") is corrected by this.
- **C2 — events travel as JSON after they are stored.** `StoredEvent` carries the serialised `{type, payload}` as `serde_json::Value`, not a typed `SystemEvent`. Deserialising every nested domain type would force `Deserialize` onto them all. The hub forwards the JSON verbatim. `DeliverySink::deliver` takes `&ClaimedDelivery`, and the sink reads the alert via `WebhookAlert` (C3).
- **C3 — `WebhookTriggered` wraps a struct.** `SystemEvent::WebhookTriggered(WebhookAlert)`, where `WebhookAlert { id, owner_id, room_id, severity, title, html_body, plain_body }` derives `Serialize` and `Deserialize`. Serde's adjacently tagged newtype over a struct produces the same `payload` object as a struct variant.
- **C4 — atomicity is per state change.** Each state change and its own event share one transaction. Cross-service compositions (a todo create followed by `ReminderService::sync_due_reminder`, a bill followed by reminders/finance) keep today's separate transactions, so the survey's transaction boundaries are frozen. A multi-row change inside one service that is currently non-atomic (`TodoService::clear_completed`) becomes one transaction covering the delete and all its events.
- **C5 — repositories stop owning transactions where events must join them.** `finance/categories.rs`, `portfolio/cash.rs` and `portfolio/trades.rs` open `pool.begin()` internally today. Their functions change to take `&mut sqlx::PgConnection`, the service owns the transaction, and the pool-opening versions are deleted (AGENTS §4.3: the service owns transaction boundaries).
- **C6 — no publisher outside services.** These places publish or write state straight from `interface/` or `llm/`; each moves behind a service in the task that converts that service:
  - `interface/http/ai.rs` (`delete_conversation`, `update_ai_config`) and `interface/chat/llm.rs` (`handle_set_model`, `handle_reset`) → `services.llm.delete_conversation` / `update_user_config`;
  - `llm/turn.rs` (assistant message + `AiConversationUpdated`) → new `LlmService::append_assistant_message`;
  - `llm/tools/bookmarks.rs` → `services.bookmarks.*`;
  - `interface/http/briefing.rs::trigger_briefing` and `interface/chat/briefing/handler.rs::generate_now` → new `BriefingService::announce_manual`.
- **C7 — retry delay.** `attempts` is incremented at claim, so a failure after claim number `n` retries after `domain::webhooks::retry_delay(n - 1)`, the same schedule as today's `retry_delay(attempts_so_far)`. A delivery is `failed` when `attempts >= max_attempts` after the claim, which is today's `attempts + 1 >= max_attempts`.
- **C8 — delivery timeout.** `sink.deliver` is wrapped in a 30 s `tokio::time::timeout`, shorter than the 60 s lease, so a hung send can never overlap a re-claim. A timeout is a failed attempt.
- **C9 — module layout.** `backend/src/events.rs` becomes the directory module `backend/src/events/` in Task 1: a crate cannot have both `events.rs` and `events/mod.rs`. `EventBroadcaster` lives in `events/broadcaster.rs` until Task 10 deletes it.

```rust
/// Where a durable copy of an event must be delivered. SSE is not a
/// destination: every instance pushes committed events to its own clients.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Destination {
    MatrixRoom(String),
}

impl Destination {
    const MATRIX: &'static str = "matrix:";

    /// The `outbox_deliveries.destination` value.
    pub fn as_key(&self) -> String {
        match self {
            Self::MatrixRoom(room) => format!("{}{room}", Self::MATRIX),
        }
    }

    pub fn parse(key: &str) -> Option<Self> {
        let room = key.strip_prefix(Self::MATRIX)?;
        (!room.is_empty()).then(|| Self::MatrixRoom(room.to_string()))
    }
}

/// What a failed delivery attempt leads to. `attempts` counts the attempt
/// that just failed (it is incremented when the delivery is claimed).
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DeliveryStep {
    /// Retry after `domain::webhooks::retry_delay(n)`.
    RetryAfterAttempts(i64),
    Fail,
}

pub fn next_delivery_step(attempts: i32, max_attempts: i32) -> DeliveryStep {
    if attempts >= max_attempts {
        DeliveryStep::Fail
    } else {
        DeliveryStep::RetryAfterAttempts(i64::from(attempts - 1).max(0))
    }
}
```

```sql
-- Step 9: transactional outbox. Every SystemEvent is written here in the
-- transaction of its state change; durable destinations get one delivery
-- row each. DDL only; webhook_outbox is dropped by 0005 once webhooks move.

CREATE TABLE outbox_events (
    id          BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    account_id  UUID NOT NULL REFERENCES accounts(id) ON DELETE CASCADE,
    event_type  TEXT NOT NULL,
    payload     JSONB NOT NULL,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_outbox_events_account_type_created
    ON outbox_events (account_id, event_type, created_at DESC);
CREATE INDEX idx_outbox_events_created ON outbox_events (created_at);

CREATE TABLE outbox_deliveries (
    id            BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    event_id      BIGINT NOT NULL REFERENCES outbox_events(id) ON DELETE CASCADE,
    destination   TEXT NOT NULL,
    status        TEXT NOT NULL DEFAULT 'pending'
                  CHECK (status IN ('pending', 'delivered', 'failed')),
    attempts      INTEGER NOT NULL DEFAULT 0,
    max_attempts  INTEGER NOT NULL DEFAULT 10,
    available_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    delivered_at  TIMESTAMPTZ,
    last_error    TEXT,
    CONSTRAINT uq_outbox_delivery UNIQUE (event_id, destination)
);

CREATE INDEX idx_outbox_deliveries_pending
    ON outbox_deliveries (available_at) WHERE status = 'pending';
CREATE INDEX idx_outbox_deliveries_event ON outbox_deliveries (event_id);

-- NOTIFY from a trigger (as 0003 does for jobs): it fires only for real
-- inserts and PostgreSQL delivers it at commit, never for a rollback.
CREATE FUNCTION outbox_notify() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
    PERFORM pg_notify('outbox', NEW.id::text || ':' || NEW.account_id::text);
    RETURN NULL;
END $$;

CREATE TRIGGER outbox_events_notify AFTER INSERT ON outbox_events
    FOR EACH ROW EXECUTE FUNCTION outbox_notify();
```

```rust
//! The transactional outbox (`outbox_events`, `outbox_deliveries`, 0004).
//!
//! `publish` is the only writer of events and takes a `Transaction`, so an
//! event can only ever be written together with the state change it
//! describes. Deliveries are claimed with a lease (`available_at` pushed
//! forward), so a crashed dispatcher's claim simply expires.

use std::time::Duration;

use chrono::{DateTime, Utc};
use sqlx::{PgExecutor, Postgres, Transaction};

use crate::domain::accounts::AccountId;
use crate::domain::events::{DeliveryId, EventId, SystemEvent};
use crate::domain::jobs::truncate_error;

/// The channel the 0004 trigger NOTIFYs with `<event id>:<account uuid>`.
pub const OUTBOX_CHANNEL: &str = "outbox";

#[derive(Debug, Clone)]
pub struct StoredEvent {
    pub id: EventId,
    pub account_id: AccountId,
    pub event_type: String,
    /// The serialised `SystemEvent` (`{type, payload}`), exactly as SSE sends it.
    pub json: serde_json::Value,
}

#[derive(Debug, Clone)]
pub struct ClaimedDelivery {
    pub id: DeliveryId,
    pub destination: String,
    /// Includes the claim that returned this row.
    pub attempts: i32,
    pub max_attempts: i32,
    pub event: StoredEvent,
}

#[derive(Debug, Clone)]
pub struct PublishedEvent {
    pub event_id: EventId,
    pub deliveries: Vec<DeliveryId>,
}

fn secs(d: Duration) -> f64 {
    d.as_secs_f64()
}

pub async fn publish(
    tx: &mut Transaction<'_, Postgres>,
    event: &SystemEvent,
) -> sqlx::Result<PublishedEvent> {
    let json = serde_json::to_value(event).map_err(|e| sqlx::Error::Encode(Box::new(e)))?;
    let event_id = sqlx::query_scalar!(
        "INSERT INTO outbox_events (account_id, event_type, payload) VALUES ($1, $2, $3) RETURNING id",
        event.owner_id().as_uuid(),
        event.event_type(),
        json,
    )
    .fetch_one(&mut **tx)
    .await?;

    let mut deliveries = Vec::new();
    for destination in event.destinations() {
        let id = sqlx::query_scalar!(
            "INSERT INTO outbox_deliveries (event_id, destination) VALUES ($1, $2) RETURNING id",
            event_id,
            destination.as_key(),
        )
        .fetch_one(&mut **tx)
        .await?;
        deliveries.push(DeliveryId(id));
    }
    Ok(PublishedEvent { event_id: EventId(event_id), deliveries })
}

struct EventRow {
    id: i64,
    account_id: uuid::Uuid,
    event_type: String,
    payload: serde_json::Value,
}

impl From<EventRow> for StoredEvent {
    fn from(r: EventRow) -> Self {
        Self {
            id: EventId(r.id),
            account_id: AccountId::from_uuid(r.account_id),
            event_type: r.event_type,
            json: r.payload,
        }
    }
}

pub async fn load(ex: impl PgExecutor<'_>, id: EventId) -> sqlx::Result<Option<StoredEvent>> {
    let row = sqlx::query_as!(
        EventRow,
        "SELECT id, account_id, event_type, payload FROM outbox_events WHERE id = $1",
        id.0
    )
    .fetch_optional(ex)
    .await?;
    Ok(row.map(Into::into))
}

pub async fn load_since(
    ex: impl PgExecutor<'_>,
    accounts: &[AccountId],
    after: EventId,
    limit: i64,
) -> sqlx::Result<Vec<StoredEvent>> {
    let uuids: Vec<uuid::Uuid> = accounts.iter().map(|a| *a.as_uuid()).collect();
    let rows = sqlx::query_as!(
        EventRow,
        r#"
        SELECT id, account_id, event_type, payload FROM outbox_events
        WHERE id > $1 AND account_id = ANY($2)
        ORDER BY id
        LIMIT $3
        "#,
        after.0,
        &uuids,
        limit
    )
    .fetch_all(ex)
    .await?;
    Ok(rows.into_iter().map(Into::into).collect())
}

struct ClaimedRow {
    id: i64,
    destination: String,
    attempts: i32,
    max_attempts: i32,
    event_id: i64,
    account_id: uuid::Uuid,
    event_type: String,
    payload: serde_json::Value,
}

impl From<ClaimedRow> for ClaimedDelivery {
    fn from(r: ClaimedRow) -> Self {
        Self {
            id: DeliveryId(r.id),
            destination: r.destination,
            attempts: r.attempts,
            max_attempts: r.max_attempts,
            event: StoredEvent {
                id: EventId(r.event_id),
                account_id: AccountId::from_uuid(r.account_id),
                event_type: r.event_type,
                json: r.payload,
            },
        }
    }
}

pub async fn claim_due(
    ex: impl PgExecutor<'_>,
    limit: i64,
    lease: Duration,
) -> sqlx::Result<Vec<ClaimedDelivery>> {
    let rows = sqlx::query_as!(
        ClaimedRow,
        r#"
        WITH due AS (
            SELECT id FROM outbox_deliveries
            WHERE status = 'pending' AND available_at <= NOW()
            ORDER BY available_at, id
            FOR UPDATE SKIP LOCKED
            LIMIT $1
        )
        UPDATE outbox_deliveries d
        SET attempts = d.attempts + 1,
            available_at = NOW() + make_interval(secs => $2)
        FROM due, outbox_events e
        WHERE d.id = due.id AND e.id = d.event_id
        RETURNING d.id, d.destination, d.attempts, d.max_attempts,
                  e.id AS event_id, e.account_id, e.event_type, e.payload
        "#,
        limit,
        secs(lease)
    )
    .fetch_all(ex)
    .await?;
    Ok(rows.into_iter().map(Into::into).collect())
}

pub async fn mark_delivered(ex: impl PgExecutor<'_>, id: DeliveryId) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE outbox_deliveries SET status = 'delivered', delivered_at = NOW() WHERE id = $1 AND status = 'pending'",
        id.0
    )
    .execute(ex)
    .await?;
    Ok(r.rows_affected() == 1)
}

pub async fn mark_retry(
    ex: impl PgExecutor<'_>,
    id: DeliveryId,
    available_at: DateTime<Utc>,
    error: &str,
) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE outbox_deliveries SET available_at = $2, last_error = $3 WHERE id = $1 AND status = 'pending'",
        id.0,
        available_at,
        truncate_error(error)
    )
    .execute(ex)
    .await?;
    Ok(r.rows_affected() == 1)
}

pub async fn mark_failed(ex: impl PgExecutor<'_>, id: DeliveryId, error: &str) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE outbox_deliveries SET status = 'failed', last_error = $2 WHERE id = $1 AND status = 'pending'",
        id.0,
        truncate_error(error)
    )
    .execute(ex)
    .await?;
    Ok(r.rows_affected() == 1)
}

pub async fn purge(ex: impl PgExecutor<'_>, older_than: Duration) -> sqlx::Result<u64> {
    let r = sqlx::query!(
        r#"
        DELETE FROM outbox_events e
        WHERE e.created_at < NOW() - make_interval(secs => $1)
          AND NOT EXISTS (
              SELECT 1 FROM outbox_deliveries d
              WHERE d.event_id = e.id AND d.status = 'pending')
        "#,
        secs(older_than)
    )
    .execute(ex)
    .await?;
    Ok(r.rows_affected())
}
```

```rust
//! `LISTEN outbox`: one per process, shared by the SSE hub and the
//! delivery dispatcher (`events::listener`).

use sqlx::postgres::PgListener;
use sqlx::PgPool;
use tracing::warn;

use crate::domain::accounts::AccountId;
use crate::domain::events::EventId;
use crate::infrastructure::postgres::repositories::outbox::OUTBOX_CHANNEL;

pub struct OutboxNotifications {
    listener: PgListener,
}

impl OutboxNotifications {
    pub async fn connect(pool: &PgPool) -> sqlx::Result<Self> {
        let mut listener = PgListener::connect_with(pool).await?;
        listener.listen(OUTBOX_CHANNEL).await?;
        Ok(Self { listener })
    }

    /// The next committed event. `Ok(None)` is a malformed payload (logged).
    pub async fn next(&mut self) -> sqlx::Result<Option<(EventId, AccountId)>> {
        let n = self.listener.recv().await?;
        let parsed = parse_payload(n.payload());
        if parsed.is_none() {
            warn!(payload = n.payload(), "Ignoring a malformed outbox notification");
        }
        Ok(parsed)
    }
}

fn parse_payload(payload: &str) -> Option<(EventId, AccountId)> {
    let (id, account) = payload.split_once(':')?;
    Some((EventId(id.parse().ok()?), AccountId::from_uuid(account.parse().ok()?)))
}
```

```rust
//! Reads and advances the outbox for the events runtime (`crate::events`).
//! Feature services write events themselves, through
//! `repositories::outbox::publish`, inside their own transactions.

use std::time::Duration;

use chrono::Utc;
use sqlx::PgPool;

use crate::application::AppError;
use crate::domain::accounts::AccountId;
use crate::domain::events::{next_delivery_step, DeliveryStep, EventId};
use crate::domain::webhooks::retry_delay;
use crate::infrastructure::postgres::repositories::outbox as repo;
pub use crate::infrastructure::postgres::repositories::outbox::{ClaimedDelivery, StoredEvent};

#[derive(Clone)]
pub struct OutboxService {
    pool: PgPool,
}

impl OutboxService {
    pub fn new(pool: PgPool) -> Self {
        Self { pool }
    }

    pub async fn load(&self, id: EventId) -> Result<Option<StoredEvent>, AppError> {
        Ok(repo::load(&self.pool, id).await?)
    }

    pub async fn load_since(&self, accounts: &[AccountId], after: EventId, limit: i64) -> Result<Vec<StoredEvent>, AppError> {
        Ok(repo::load_since(&self.pool, accounts, after, limit).await?)
    }

    pub async fn claim_due(&self, limit: i64, lease: Duration) -> Result<Vec<ClaimedDelivery>, AppError> {
        Ok(repo::claim_due(&self.pool, limit, lease).await?)
    }

    pub async fn record_delivered(&self, delivery: &ClaimedDelivery) -> Result<(), AppError> {
        let mut tx = self.pool.begin().await?;
        repo::mark_delivered(&mut *tx, delivery.id).await?;
        tx.commit().await?;
        Ok(())
    }

    /// Schedules the next attempt, or fails the delivery after its last one.
    pub async fn record_failure(&self, delivery: &ClaimedDelivery, error: &str) -> Result<DeliveryStep, AppError> {
        let step = next_delivery_step(delivery.attempts, delivery.max_attempts);
        let mut tx = self.pool.begin().await?;
        match step {
            DeliveryStep::RetryAfterAttempts(n) => {
                repo::mark_retry(&mut *tx, delivery.id, Utc::now() + retry_delay(n), error).await?;
            }
            DeliveryStep::Fail => {
                repo::mark_failed(&mut *tx, delivery.id, error).await?;
            }
        }
        tx.commit().await?;
        Ok(step)
    }

    pub async fn purge(&self, older_than: Duration) -> Result<u64, AppError> {
        Ok(repo::purge(&self.pool, older_than).await?)
    }
}
```

```rust
//! The SSE hub: this instance's connected browsers, keyed by account.
//!
//! Ownership is structural — a subscription is registered only under the
//! account that authenticated it, and a line is only ever pushed to that
//! account's subscriptions. A subscriber whose bounded channel is full is
//! dropped (never awaited): its browser reconnects and refetches.

use std::collections::HashMap;
use std::pin::Pin;
use std::sync::{Arc, Mutex};
use std::task::{Context, Poll};

use futures_util::Stream;
use tokio::sync::mpsc;
use tracing::warn;

use crate::application::outbox::{OutboxService, StoredEvent};
use crate::domain::accounts::AccountId;
use crate::domain::events::EventId;

#[derive(Debug, PartialEq, Eq)]
pub enum Notified {
    NoSubscriber,
    Missing,
    Delivered(usize),
    LoadFailed,
}

#[derive(Default)]
struct State {
    next_key: u64,
    subscribers: HashMap<AccountId, Vec<(u64, mpsc::Sender<Arc<str>>)>>,
    /// Highest event id pushed; replay starts just below it.
    last_seen: i64,
}

#[derive(Clone)]
pub struct Hub {
    state: Arc<Mutex<State>>,
    outbox: OutboxService,
    capacity: usize,
}

pub struct Subscription {
    rx: mpsc::Receiver<Arc<str>>,
    _guard: Guard,
}

struct Guard {
    state: Arc<Mutex<State>>,
    account: AccountId,
    key: u64,
}

impl Drop for Guard {
    fn drop(&mut self) {
        let Ok(mut state) = self.state.lock() else { return };
        if let Some(list) = state.subscribers.get_mut(&self.account) {
            list.retain(|(k, _)| *k != self.key);
            if list.is_empty() {
                state.subscribers.remove(&self.account);
            }
        }
    }
}

impl Stream for Subscription {
    type Item = Arc<str>;
    fn poll_next(mut self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Option<Self::Item>> {
        self.rx.poll_recv(cx)
    }
}

impl Hub {
    pub fn new(outbox: OutboxService, capacity: usize) -> Self {
        Self { state: Arc::default(), outbox, capacity }
    }

    pub fn subscribe(&self, account: AccountId) -> Subscription {
        let (tx, rx) = mpsc::channel(self.capacity);
        let key = {
            let mut state = self.state.lock().unwrap_or_else(|p| p.into_inner());
            state.next_key += 1;
            let key = state.next_key;
            state.subscribers.entry(account).or_default().push((key, tx));
            key
        };
        Subscription { rx, _guard: Guard { state: self.state.clone(), account, key } }
    }

    fn has_subscriber(&self, account: &AccountId) -> bool {
        let state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        state.subscribers.contains_key(account)
    }

    fn accounts(&self) -> Vec<AccountId> {
        let state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        state.subscribers.keys().copied().collect()
    }

    /// Pushes one line to every subscription of `account`; returns how many
    /// received it. Never blocks: a full or closed channel is removed.
    pub(crate) fn push(&self, account: &AccountId, line: Arc<str>) -> usize {
        let mut state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        let Some(list) = state.subscribers.get_mut(account) else { return 0 };
        list.retain(|(_, tx)| tx.try_send(line.clone()).is_ok());
        let n = list.len();
        if n == 0 {
            state.subscribers.remove(account);
        }
        n
    }

    fn forward(&self, event: &StoredEvent) -> usize {
        let line: Arc<str> = Arc::from(event.json.to_string());
        let n = self.push(&event.account_id, line);
        let mut state = self.state.lock().unwrap_or_else(|p| p.into_inner());
        state.last_seen = state.last_seen.max(event.id.0);
        n
    }

    pub(crate) async fn on_notification(&self, id: EventId, account: AccountId) -> Notified {
        if !self.has_subscriber(&account) {
            return Notified::NoSubscriber;
        }
        match self.outbox.load(id).await {
            Ok(Some(event)) => Notified::Delivered(self.forward(&event)),
            Ok(None) => Notified::Missing,
            Err(err) => {
                warn!(error = %err, event_id = id.0, "Could not load an outbox event for SSE");
                Notified::LoadFailed
            }
        }
    }

    /// After a listener reconnect: re-sends recent events for connected
    /// accounts. `window` reaches below `last_seen` because identity ids can
    /// commit out of order; duplicates only re-invalidate browser caches.
    pub(crate) async fn replay(&self, window: i64, limit: i64) {
        let accounts = self.accounts();
        if accounts.is_empty() {
            return;
        }
        let after = {
            let state = self.state.lock().unwrap_or_else(|p| p.into_inner());
            EventId((state.last_seen - window).max(0))
        };
        match self.outbox.load_since(&accounts, after, limit).await {
            Ok(events) => {
                for event in &events {
                    self.forward(event);
                }
            }
            Err(err) => warn!(error = %err, "SSE replay after a listener reconnect failed"),
        }
    }
}
```

```rust
//! One `LISTEN outbox` per process. Each committed event goes to the SSE
//! hub; the dispatcher is woken. On every (re)connect the hub replays and
//! the dispatcher is woken once, because a NOTIFY sent while the listener
//! was down is gone.

use std::sync::Arc;
use std::time::Duration;

use sqlx::PgPool;
use tokio::sync::Notify;
use tokio_util::sync::CancellationToken;
use tracing::warn;

use crate::events::hub::Hub;
use crate::events::EventsConfig;
use crate::infrastructure::postgres::outbox_notifications::OutboxNotifications;

pub(crate) async fn run(pool: PgPool, hub: Hub, wake: Arc<Notify>, config: Arc<EventsConfig>, shutdown: CancellationToken) {
    loop {
        tokio::select! {
            _ = shutdown.cancelled() => return,
            result = listen(&pool, &hub, &wake, &config) => {
                let Err(err) = result;
                warn!(error = %err, "Outbox LISTEN failed; SSE pauses, deliveries fall back to polling");
            }
        }
        tokio::select! {
            _ = shutdown.cancelled() => return,
            _ = tokio::time::sleep(config.listener_retry) => {}
        }
    }
}

async fn listen(pool: &PgPool, hub: &Hub, wake: &Notify, config: &EventsConfig) -> sqlx::Result<std::convert::Infallible> {
    let mut listener = OutboxNotifications::connect(pool).await?;
    wake.notify_waiters();
    hub.replay(config.replay_window, config.replay_limit).await;
    loop {
        if let Some((id, account)) = listener.next().await? {
            hub.on_notification(id, account).await;
            wake.notify_waiters();
        }
    }
}
```

```rust
    /// Runs until `shutdown`; a task ending earlier is a bug, logged, and
    /// ends the runtime so `app::run` supervision stops the process.
    pub async fn run(self, shutdown: CancellationToken) {
        let wake = Arc::new(Notify::new());
        let mut tasks = JoinSet::new();
        tasks.spawn(listener::run(self.pool.clone(), self.hub.clone(), wake.clone(), self.config.clone(), shutdown.clone()));
        tasks.spawn(purge::run(self.services.outbox.clone(), self.config.clone(), shutdown.clone()));
        tasks.spawn(bridge::run(self.legacy.clone(), self.hub.clone(), shutdown.clone()));
        while let Some(result) = tasks.join_next().await {
            if !shutdown.is_cancelled() {
                error!(?result, "An events runtime task ended before shutdown");
                shutdown.cancel();
            }
        }
    }
```

### Service conversion pattern (Tasks 4–8)

Each of Tasks 4–8 applies the same pattern to a group of services. The canonical before/after is `TodoService::create`:

**Before**
```rust
let item = repositories::todos::create(&self.pool, owner_id, &input).await?;
let sync_outcome = self.sync_reminder_for_todo(&item, remind_room.as_deref()).await?;
self.broadcast_created(&item);
```

**After** (C4: the todo row and its event share a transaction; the reminder sync keeps its own)
```rust
let mut tx = self.pool.begin().await?;
let item = repositories::todos::create(&mut *tx, owner_id, &input).await?;
outbox::publish(&mut tx, &SystemEvent::TodoCreated(item.clone())).await?;
tx.commit().await?;
let sync_outcome = self.sync_reminder_for_todo(&item, remind_room.as_deref()).await?;
```

with `use crate::infrastructure::postgres::repositories::outbox;` at the top.

Rules:
1. Every `self.events.send(ev)` / `self.broadcaster.send(ev)` becomes `outbox::publish(&mut tx, &ev).await?` inside the transaction of the write that justifies it. If the method had no transaction, open one around that write. A read that decides whether to write (e.g. `find_owned` before `delete`) may stay outside it, unless the method already locked the row.
2. A repository function taking `&PgPool` changes to `impl sqlx::PgExecutor<'_>` so it can run on `&mut *tx`. A function that opens its own transaction changes to take `&mut sqlx::PgConnection` and loses the `begin`/`commit` (C5); the service opens the transaction.
3. **An event published after a conditional check keeps its condition.** For example, `LlmService::delete_conversation` publishes only when `deleted` is true: open the transaction, delete, `if deleted { publish }`, commit.
4. Remove the `events`/`broadcaster` field and constructor parameter from the converted service, and its argument in `AppServices::with_events`. Delete helper fns such as `broadcast_created` that only sent.

```rust
//! Delivers durable outbox copies (spec §5.4). One task per process;
//! `SKIP LOCKED` keeps several processes apart and the claim lease makes a
//! crashed claim reappear. Idles while the sink is not ready, so a Matrix
//! outage burns no attempts.

use std::sync::Arc;

use async_trait::async_trait;
use tokio::sync::Notify;
use tokio_util::sync::CancellationToken;
use tracing::{info, warn};

use crate::application::outbox::{ClaimedDelivery, OutboxService};
use crate::domain::events::DeliveryStep;
use crate::events::EventsConfig;

#[async_trait]
pub trait DeliverySink: Send + Sync {
    /// False while the channel is down.
    fn is_ready(&self) -> bool;
    async fn deliver(&self, delivery: &ClaimedDelivery) -> Result<(), String>;
}

pub(crate) async fn run(
    outbox: OutboxService,
    sink: Arc<dyn DeliverySink>,
    wake: Arc<Notify>,
    config: Arc<EventsConfig>,
    shutdown: CancellationToken,
) {
    loop {
        // Register before draining so a NOTIFY during the drain is not lost.
        let notified = wake.notified();
        tokio::pin!(notified);
        notified.as_mut().enable();
        loop {
            if shutdown.is_cancelled() {
                return;
            }
            let handled = dispatch_once(&outbox, sink.as_ref(), &config).await;
            if handled < config.batch as usize {
                break;
            }
        }
        tokio::select! {
            _ = shutdown.cancelled() => return,
            _ = &mut notified => {}
            _ = tokio::time::sleep(config.poll_interval) => {}
        }
    }
}

/// Claims and delivers one batch; returns how many were claimed.
pub(crate) async fn dispatch_once(outbox: &OutboxService, sink: &dyn DeliverySink, config: &EventsConfig) -> usize {
    if !sink.is_ready() {
        return 0;
    }
    let claimed = match outbox.claim_due(config.batch, config.lease).await {
        Ok(c) => c,
        Err(err) => {
            warn!(error = %err, "Could not claim outbox deliveries");
            return 0;
        }
    };
    for delivery in &claimed {
        let outcome = match tokio::time::timeout(config.deliver_timeout, sink.deliver(delivery)).await {
            Ok(result) => result,
            Err(_) => Err(format!("delivery timed out after {:?}", config.deliver_timeout)),
        };
        match outcome {
            Ok(()) => {
                info!(delivery_id = delivery.id.0, destination = %delivery.destination, "Delivered outbox event");
                if let Err(err) = outbox.record_delivered(delivery).await {
                    warn!(error = %err, delivery_id = delivery.id.0, "Delivered but could not record it; the lease will retry it");
                }
            }
            Err(msg) => match outbox.record_failure(delivery, &msg).await {
                Ok(DeliveryStep::Fail) => warn!(delivery_id = delivery.id.0, attempts = delivery.attempts, error = %msg, "Outbox delivery failed permanently"),
                Ok(DeliveryStep::RetryAfterAttempts(_)) => warn!(delivery_id = delivery.id.0, attempts = delivery.attempts, error = %msg, "Outbox delivery failed; will retry"),
                Err(err) => warn!(error = %err, delivery_id = delivery.id.0, "Could not record a failed delivery; the lease will retry it"),
            },
        }
    }
    claimed.len()
}
```

```rust
//! Delivers `matrix:<room>` outbox copies (webhook alerts) through the bot's
//! current Matrix client. Checks are today's webhook worker checks; every
//! error is retryable (frozen). The delivery id is the Matrix transaction
//! id, so a resend after a crash within one session is deduplicated by the

use matrix_sdk::ruma::{events::room::message::RoomMessageEventContent, OwnedTransactionId, RoomId};

use crate::application::outbox::ClaimedDelivery;

    services: AppServices,
}

    pub fn new(handle: MatrixHandle, services: AppServices) -> Self {
        Self { handle, services }
    }

pub(crate) fn transaction_id(delivery: &ClaimedDelivery) -> OwnedTransactionId {
    OwnedTransactionId::from(format!("outbox-{}", delivery.id))
}

#[async_trait]
impl DeliverySink for MatrixRoomSink {
    fn is_ready(&self) -> bool {
        self.handle.current().is_some()
    }

    async fn deliver(&self, delivery: &ClaimedDelivery) -> Result<(), String> {
        let Some(Destination::MatrixRoom(room)) = Destination::parse(&delivery.destination) else {
            return Err(format!("Unsupported destination: {}", delivery.destination));
        };
        let alert: WebhookAlert = serde_json::from_value(delivery.event.json["payload"].clone())
            .map_err(|e| format!("Unreadable webhook alert: {e}"))?;
        let client = self.handle.current().ok_or("Matrix is not connected")?;
        let room_id = <&RoomId>::try_from(room.as_str()).map_err(|_| format!("Invalid Matrix room ID: {room}"))?;
        let joined = client.get_room(room_id).ok_or_else(|| format!("Bot is not joined to room: {room}"))?;
        let authorized = crate::interface::chat::rooms::is_room_authorized_for_account(
            &self.services.rooms, Some(&client), &delivery.event.account_id, &room,
        ).await;
        if !authorized {
            return Err(format!("Delivery rejected: owner {} is not joined to room {room}", delivery.event.account_id));
        }
        let content = RoomMessageEventContent::text_html(&alert.plain_body, &alert.html_body);
        joined
            .send(content)
            .with_transaction_id(transaction_id(delivery))
            .await
            .map_err(|err| format!("Matrix homeserver delivery failed: {err:?}"))?;
        Ok(())
    }
}
```
