# Step 8: Durable Job Queue — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the reminder, briefing and portfolio polling loops with a durable, retried, leader-scheduled PostgreSQL job queue that survives restarts and no longer depends on a Matrix sync generation.

**Architecture:** A `jobs` table (migration 0003) with compile-checked queue queries in `infrastructure/postgres/repositories/jobs.rs`; a runtime in `backend/src/jobs/` (workers + heartbeat, reaper/purge, advisory-lock scheduler, `LISTEN jobs` wake-ups) spawned by `app::run` under a child `CancellationToken`; job handlers in `interface/jobs/` that call application services and deliver through a `Delivery` seam backed by a `MatrixHandle` the sync loop publishes. Pure rules (job policy, backoff, due-ness) live in `domain/`, enqueue use cases in `application/`.

**Tech Stack:** Rust 2021, tokio 1 / tokio-util 0.7.19 (`CancellationToken`), sqlx 0.9 (`query!`, `PgListener`, `PoolConnection::detach`), PostgreSQL 18, matrix-sdk 0.18, async-trait, serde/serde_json, futures-util (`BoxFuture`).

**Spec:** `docs/superpowers/specs/2026-09-29-job-queue-design.md` (approved 2026-09-29; rulings R17–R22 are binding and are not reopened here). Parent: `docs/superpowers/specs/2026-09-24-postgres-foundation-design.md` §5.1.

### Clarifications forced by the code (decided here, recorded in HANDOFF §9 by Task 12)

- **C1 — `jobs` goes into `ACCOUNT_ID_FOLLOWS`, not `OWNED_TABLES`.** `OWNED_TABLES` lists `owner_id` tables; `jobs` has `account_id`. `accounts::tests::test_account_id_tables_are_all_classified` classifies by column name and would fail otherwise; `ACCOUNT_ID_FOLLOWS` is the list whose rows `MergeService` moves with `account_id` (`application/accounts/merge.rs:73`). Intent of the design (pending jobs follow a merge) is unchanged.
- **C2 — `JobContext` carries `account_id: Option<AccountId>` from the job row.** Account-scoped handlers (`briefing.send`, `portfolio.refresh_prices`) read the subject from the row, not the payload, so a job moved by a merge acts on the surviving account. `reminder.fire` still resolves by reminder row id (design §6).
- **C3 — reminder retries keep `trigger_at` fixed.** Today's `increment_retry` also moves `trigger_at`, which would change the dedupe key `<id>:<trigger_at>` and make the handler's "still pending at that trigger_at" check skip its own retries. It is replaced by `record_failed_attempt(id, trigger_at, attempt)` (sets `retry_count = attempt`, guarded by `status='pending' AND trigger_at=$2`); backoff is owned by the job row (R21).
- **C4 — `retry` takes the computed delay.** Signature `retry(exec, id, worker, error, delay: Duration)`; the worker computes `domain::jobs::backoff_delay(backoff_seconds, attempts)`, so the backoff rule is one pure, unit-tested function instead of SQL arithmetic. SQL still decides `pending` vs `failed` from `attempts >= max_attempts`.
- **C5 — `NOTIFY jobs` is sent by an `AFTER INSERT … FOR EACH ROW` trigger in 0003,** not by the `enqueue` statement. A row trigger fires only for rows actually inserted (not for `ON CONFLICT DO NOTHING` skips), is delivered at commit, and avoids selecting a `void` column through `query!`. Observable behaviour is what design §4.1 specifies.
- **C6 — the Matrix handoff file is `interface/channels/matrix/live_client.rs`** (type `MatrixHandle` as designed). `handles.rs` (`BotHandles`) already exists next to it; `handle.rs` beside `handles.rs` invites mistakes. `MatrixHandle` becomes a field of `BotHandles` so `app.rs` shares one instance with the sync loop.
- **C7 — a `Delivery` trait (`interface/jobs/mod.rs`) is the "delivery seam" of design §7,** implemented by `MatrixDelivery` (`interface/channels/matrix/delivery.rs`) and by a fake in tests. It is a real external-service boundary with a second implementation (the test fake), which AGENTS.md §3.2 permits. Reminder and briefing room sends share its join-and-retry fallback; for briefing this changes only the "delivered" log flag when a post-join send fails (today it logged `delivered: true`).
- Naming: the service is `ReminderService` (not `RemindersService` as the design writes); `enqueue_due` is added to it.

### Risks

| Risk | Mitigation in this plan |
|---|---|
| A session advisory lock taken on a pooled connection that is returned to the pool stays held by whatever borrows that connection next (and is never released). | `LeaderLock` (`infrastructure/postgres/advisory.rs`) takes its connection with `pool.acquire().await?.detach()` (sqlx 0.9 `PoolConnection::detach` → owned `PgConnection`, pool opens a replacement), so it can never go back to the pool. Release = `pg_advisory_unlock` + `Connection::close`; any drop closes the socket, which ends the session and frees the lock. A failed `try_lock` closes the detached connection too. |
| Advisory locks and `NOTIFY` are database-wide, while tests isolate by schema and run in parallel (and several `cargo test` processes can share the container). | Scheduler tests use a random lock key per test (`JobsConfig::for_tests`). Tests only assert that a notification **arrives**, never that none does. |
| `PgListener::connect_with(&pool)` (sqlx 0.9, `listener.rs:60`) holds one pool connection for its lifetime, and `recv()` returns `Err(PoolClosed)` once the pool closes. | One listener per process (`jobs/wakeup.rs`) fans out through `tokio::sync::Notify`; it reconnects after 30 s on error and workers still poll every 5 s. The runtime is joined before `app::run` closes the pool. Docs note that `JOB_WORKERS` + listener + HTTP must fit `DATABASE_MAX_CONNECTIONS` (default 10, workers default 4). |
| `tokio::select!` evaluates every branch's future expression even when its precondition is false. | The shutdown-grace branch uses `sleep_until(grace_until.unwrap_or(far_future))`, never `unwrap()`. |
| Heartbeats, reaping and purge use DB `NOW()`, so runtime tests cannot use `tokio::time::pause`. | Runtime tests use real time with sub-second intervals from `JobsConfig::for_tests` and generous `wait_for_status` timeouts (10 s). |
| Migrating the shared container's public schema to 0003 for `sqlx prepare` affects any other worktree that runs `sqlx migrate` against the same public schema. | Only the throwaway `pg18-test` container is used; tests use private schemas and are unaffected. |
| A `reminder.fire` job failed by the **reaper** (5 crashes mid-delivery) leaves the reminder `pending` with a used dedupe key, so it is not re-enqueued until `purge_finished` deletes the job 7 days later. | Accepted, recorded in HANDOFF §11 (needs five consecutive worker crashes on one reminder). |
| sqlx `query!` type inference for `COALESCE($7, NOW())`, `make_interval(secs => $n)` and `= ANY($2)`. | Explicit casts are written in the SQL below (`$7::timestamptz`, `$4::float8`, `$3::text[]`). |

```sql
-- 0003_jobs.sql: durable job queue (design step 8).
-- Spec: docs/superpowers/specs/2026-09-29-job-queue-design.md §3
-- Plain DDL; sqlx runs this file in one transaction.

CREATE TABLE jobs (
    id              BIGINT GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    account_id      UUID REFERENCES accounts(id) ON DELETE CASCADE,
    job_type        TEXT NOT NULL,
    payload         JSONB NOT NULL DEFAULT '{}'::jsonb,
    status          TEXT NOT NULL DEFAULT 'pending'
                    CHECK (status IN ('pending','running','completed','failed','cancelled')),
    priority        SMALLINT NOT NULL DEFAULT 0,
    attempts        INTEGER NOT NULL DEFAULT 0,
    max_attempts    INTEGER NOT NULL DEFAULT 3 CHECK (max_attempts >= 1),
    backoff_seconds INTEGER NOT NULL DEFAULT 10 CHECK (backoff_seconds >= 0),
    available_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    locked_at       TIMESTAMPTZ,
    locked_by       TEXT,
    started_at      TIMESTAMPTZ,
    completed_at    TIMESTAMPTZ,
    heartbeat_at    TIMESTAMPTZ,
    dedupe_key      TEXT,
    error           TEXT,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_jobs_dedupe UNIQUE (job_type, dedupe_key)
);

CREATE INDEX idx_jobs_dequeue ON jobs (priority DESC, available_at ASC) WHERE status = 'pending';
CREATE INDEX idx_jobs_running ON jobs (heartbeat_at) WHERE status = 'running';
CREATE INDEX idx_jobs_finished ON jobs (completed_at) WHERE status IN ('completed','failed','cancelled');
CREATE INDEX idx_jobs_account ON jobs (account_id);

-- Wakes idle workers (LISTEN jobs). A row trigger fires only for rows really
-- inserted, so an ON CONFLICT DO NOTHING skip sends nothing; NOTIFY is
-- delivered at commit, so a worker never sees an uncommitted job.
CREATE FUNCTION jobs_notify() RETURNS trigger LANGUAGE plpgsql AS $$
BEGIN
    PERFORM pg_notify('jobs', '');
    RETURN NULL;
END
$$;

CREATE TRIGGER jobs_notify AFTER INSERT ON jobs
    FOR EACH ROW EXECUTE FUNCTION jobs_notify();
```

```rust
    pub fn reminder_fire(owner: AccountId, reminder_id: i64, trigger_at: DateTime<Utc>) -> Self {
```

```rust
/// Delay before retry number `attempt + 1`: `backoff · 2^(attempt-1)`,
/// attempt counted from 1, capped at [`MAX_BACKOFF`].
pub fn backoff_delay(backoff_seconds: i32, attempt: i32) -> Duration {
    let base = u64::try_from(backoff_seconds.max(0)).unwrap_or(0);
    let exponent = u32::try_from((attempt.max(1) - 1).min(20)).unwrap_or(20);
    let secs = base.saturating_mul(1u64 << exponent);
    Duration::from_secs(secs).min(MAX_BACKOFF)
}

/// Error text as stored on a job row: at most [`MAX_ERROR_CHARS`] characters.
pub fn truncate_error(message: &str) -> String {
    message.chars().take(MAX_ERROR_CHARS).collect()
}
```

```rust
//! The durable job queue (`jobs`, migration 0003).
//!
//! Every transition after `claim` is guarded by `locked_by = worker AND
//! status = 'running'`: a worker whose job was reaped and re-claimed can
//! never overwrite the new owner's state — the call returns `false`.

use std::time::Duration;

use sqlx::PgExecutor;

use crate::domain::accounts::AccountId;
use crate::domain::jobs::{truncate_error, JobId, JobPayload, NewJob};

/// The channel the 0003 trigger NOTIFYs on every inserted job.
pub const JOBS_CHANNEL: &str = "jobs";

#[derive(Debug, Clone)]
pub struct ClaimedJob {
    pub id: JobId,
    pub job_type: String,
    pub account_id: Option<AccountId>,
    pub payload: serde_json::Value,
    pub attempts: i32,
    pub max_attempts: i32,
    pub backoff_seconds: i32,
}

struct ClaimedRow {
    id: i64,
    job_type: String,
    account_id: Option<uuid::Uuid>,
    payload: serde_json::Value,
    attempts: i32,
    max_attempts: i32,
    backoff_seconds: i32,
}

impl From<ClaimedRow> for ClaimedJob {
    fn from(r: ClaimedRow) -> Self {
        Self {
            id: JobId(r.id),
            job_type: r.job_type,
            account_id: r.account_id.map(AccountId::from_uuid),
            payload: r.payload,
            attempts: r.attempts,
            max_attempts: r.max_attempts,
            backoff_seconds: r.backoff_seconds,
        }
    }
}

fn payload_json(payload: &JobPayload) -> sqlx::Result<serde_json::Value> {
    let value = match payload {
        JobPayload::ReminderFire(p) => serde_json::to_value(p),
        JobPayload::BriefingSend(p) => serde_json::to_value(p),
        JobPayload::Empty => Ok(serde_json::json!({})),
    };
    value.map_err(|e| sqlx::Error::Encode(Box::new(e)))
}

fn secs(d: Duration) -> f64 {
    d.as_secs_f64()
}

/// Inserts `job` unless one with the same `(job_type, dedupe_key)` exists
/// (in any state). `None` means it was a duplicate.
pub async fn enqueue(exec: impl PgExecutor<'_>, job: &NewJob) -> sqlx::Result<Option<JobId>> {
    let payload = payload_json(job.payload())?;
    let id = sqlx::query_scalar!(
        r#"
        INSERT INTO jobs (job_type, account_id, payload, priority, max_attempts,
                          backoff_seconds, available_at, dedupe_key)
        VALUES ($1, $2, $3, $4, $5, $6, COALESCE($7::timestamptz, NOW()), $8)
        ON CONFLICT (job_type, dedupe_key) DO NOTHING
        RETURNING id
        "#,
        job.job_type().as_str(),
        job.account_id().map(|a| *a.as_uuid()),
        payload,
        job.priority(),
        job.max_attempts(),
        job.backoff_seconds(),
        job.available_at(),
        job.dedupe_key(),
    )
    .fetch_optional(exec)
    .await?;
    Ok(id.map(JobId))
}

/// SPEC §5.2: the next due job of one of `types`, `SKIP LOCKED`.
pub async fn claim(exec: impl PgExecutor<'_>, worker: &str, types: &[&str])
    -> sqlx::Result<Option<ClaimedJob>> {
    let row = sqlx::query_as!(
        ClaimedRow,
        r#"
        WITH next_job AS (
            SELECT id FROM jobs
            WHERE status = 'pending' AND available_at <= NOW() AND job_type = ANY($2::text[])
            ORDER BY priority DESC, available_at ASC, id ASC
            LIMIT 1
            FOR UPDATE SKIP LOCKED
        )
        UPDATE jobs
        SET status = 'running', locked_at = NOW(), locked_by = $1, started_at = NOW(),
            heartbeat_at = NOW(), attempts = jobs.attempts + 1, updated_at = NOW()
        FROM next_job
        WHERE jobs.id = next_job.id
        RETURNING jobs.id, jobs.job_type, jobs.account_id, jobs.payload,
                  jobs.attempts, jobs.max_attempts, jobs.backoff_seconds
        "#,
        worker,
        types as &[&str],
    )
    .fetch_optional(exec)
    .await?;
    Ok(row.map(Into::into))
}

pub async fn heartbeat(exec: impl PgExecutor<'_>, id: JobId, worker: &str) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE jobs SET heartbeat_at = NOW(), updated_at = NOW() \
         WHERE id = $1 AND locked_by = $2 AND status = 'running'",
        id.0, worker)
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

pub async fn complete(exec: impl PgExecutor<'_>, id: JobId, worker: &str) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE jobs SET status = 'completed', completed_at = NOW(), heartbeat_at = NULL, \
                locked_at = NULL, updated_at = NOW() \
         WHERE id = $1 AND locked_by = $2 AND status = 'running'",
        id.0, worker)
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

/// A failed attempt: pending again after `delay`, or `failed` once
/// `attempts >= max_attempts`.
pub async fn retry(exec: impl PgExecutor<'_>, id: JobId, worker: &str, error: &str, delay: Duration)
    -> sqlx::Result<bool> {
    let r = sqlx::query!(
        r#"
        UPDATE jobs SET
            status       = CASE WHEN attempts >= max_attempts THEN 'failed' ELSE 'pending' END,
            available_at = CASE WHEN attempts >= max_attempts THEN available_at
                                ELSE NOW() + make_interval(secs => $4::float8) END,
            completed_at = CASE WHEN attempts >= max_attempts THEN NOW() END,
            error = $3, locked_at = NULL, locked_by = NULL, heartbeat_at = NULL, updated_at = NOW()
        WHERE id = $1 AND locked_by = $2 AND status = 'running'
        "#,
        id.0, worker, truncate_error(error), secs(delay))
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

/// A dependency is down: try again after `delay` without spending the attempt.
pub async fn defer(exec: impl PgExecutor<'_>, id: JobId, worker: &str, delay: Duration) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE jobs SET status = 'pending', attempts = attempts - 1, \
                available_at = NOW() + make_interval(secs => $3::float8), \
                locked_at = NULL, locked_by = NULL, heartbeat_at = NULL, updated_at = NOW() \
         WHERE id = $1 AND locked_by = $2 AND status = 'running'",
        id.0, worker, secs(delay))
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

pub async fn fail(exec: impl PgExecutor<'_>, id: JobId, worker: &str, error: &str) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE jobs SET status = 'failed', completed_at = NOW(), error = $3, \
                locked_at = NULL, locked_by = NULL, heartbeat_at = NULL, updated_at = NOW() \
         WHERE id = $1 AND locked_by = $2 AND status = 'running'",
        id.0, worker, truncate_error(error))
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

/// Shutdown: hand the job back untouched (the attempt is not spent).
pub async fn release(exec: impl PgExecutor<'_>, id: JobId, worker: &str) -> sqlx::Result<bool> {
    let r = sqlx::query!(
        "UPDATE jobs SET status = 'pending', attempts = attempts - 1, available_at = NOW(), \
                locked_at = NULL, locked_by = NULL, heartbeat_at = NULL, updated_at = NOW() \
         WHERE id = $1 AND locked_by = $2 AND status = 'running'",
        id.0, worker)
        .execute(exec).await?;
    Ok(r.rows_affected() == 1)
}

/// SPEC §5.3 reaper: a running job whose heartbeat is older than
/// `older_than` lost its worker. The attempt counts.
pub async fn reap_stale(exec: impl PgExecutor<'_>, older_than: Duration) -> sqlx::Result<u64> {
    let r = sqlx::query!(
        r#"
        UPDATE jobs SET
            status       = CASE WHEN attempts >= max_attempts THEN 'failed' ELSE 'pending' END,
            completed_at = CASE WHEN attempts >= max_attempts THEN NOW() END,
            error        = 'worker lost: heartbeat stale',
            available_at = NOW(), locked_at = NULL, locked_by = NULL, heartbeat_at = NULL,
            updated_at   = NOW()
        WHERE status = 'running' AND heartbeat_at < NOW() - make_interval(secs => $1::float8)
        "#,
        secs(older_than))
        .execute(exec).await?;
    Ok(r.rows_affected())
}

pub async fn purge_finished(exec: impl PgExecutor<'_>, older_than: Duration) -> sqlx::Result<u64> {
    let r = sqlx::query!(
        "DELETE FROM jobs WHERE status IN ('completed', 'failed', 'cancelled') \
           AND completed_at < NOW() - make_interval(secs => $1::float8)",
        secs(older_than))
        .execute(exec).await?;
    Ok(r.rows_affected())
}
```

```rust
    /// Runs until `shutdown` fires, then waits for every task (workers get
    /// `shutdown_grace` to finish or release their job). Any task ending
    /// before shutdown is a bug: it is logged and the runtime stops, which
    /// `app::run`'s supervision turns into a process restart.
    pub async fn run(self, shutdown: CancellationToken) {
        let wake = Arc::new(Notify::new());
        let mut tasks = JoinSet::new();
        tasks.spawn(wakeup::run(self.pool.clone(), wake.clone(), Duration::from_secs(30), shutdown.clone()));
        for _ in 0..self.config.workers {
            let w = worker::Worker { id: worker_id(&self.config.worker_host), pool: self.pool.clone(),
                registry: self.registry.clone(), config: self.config.clone(), wake: wake.clone() };
            tasks.spawn(worker::run(w, shutdown.clone()));
        }
        info!(workers = self.config.workers, types = ?self.registry.type_names(), "Job runtime started");
        while let Some(result) = tasks.join_next().await {
            if !shutdown.is_cancelled() {
                error!(?result, "A job runtime task ended before shutdown; stopping the runtime");
                shutdown.cancel();
            }
        }
        info!("Job runtime stopped");
    }
}
```

```rust
enum Execution { Finished(Result<(), JobError>), Abandoned }

impl Worker {
    async fn run_one(&self, job: ClaimedJob, shutdown: &CancellationToken) {
        let span = tracing::info_span!("job", job_id = %job.id, job_type = %job.job_type, attempt = job.attempts);
        async {
            let Some(handler) = self.registry.get(&job.job_type) else {
                // claim() only returns registered types; a hit here is a bug.
                self.record(&job, Err(JobError::Permanent(anyhow::anyhow!("no handler registered")))).await;
                return;
            };
            let started = std::time::Instant::now();
            match self.execute(handler.as_ref(), &job, shutdown).await {
                Execution::Finished(result) => {
                    self.record(&job, result).await;
                    info!(elapsed_ms = started.elapsed().as_millis() as u64, "Job finished");
                }
                Execution::Abandoned => {
                    match repo::release(&self.pool, job.id, &self.id).await {
                        Ok(_) => warn!("Handler overran the shutdown grace; job released"),
                        Err(err) => warn!(error = %err, "Releasing the job failed; the reaper will reclaim it"),
                    }
                }
            }
        }
        .instrument(span)
        .await
    }

    async fn execute(&self, handler: &dyn JobHandler, job: &ClaimedJob, shutdown: &CancellationToken) -> Execution {
        let cancel = shutdown.child_token();
        let ctx = JobContext { job_id: job.id, account_id: job.account_id, attempt: job.attempts,
                               max_attempts: job.max_attempts, cancel: cancel.clone() };
        let limit = handler.timeout();
        let run = tokio::time::timeout(limit, handler.run(&ctx, job.payload.clone()));
        tokio::pin!(run);
        let period = self.config.heartbeat_interval;
        let mut beat = tokio::time::interval_at(tokio::time::Instant::now() + period, period);
        // select! evaluates every branch expression even when its guard is
        // false, so the grace sleep needs a real deadline, never an unwrap.
        let far = tokio::time::Instant::now() + Duration::from_secs(365 * 86_400);
        let mut grace_until: Option<tokio::time::Instant> = None;
        loop {
            tokio::select! {
                result = &mut run => {
                    return Execution::Finished(result.unwrap_or_else(|_| {
                        Err(JobError::Retryable(anyhow::anyhow!("timed out after {limit:?}")))
                    }));
                }
                _ = beat.tick() => self.beat(job, &cancel).await,
                _ = shutdown.cancelled(), if grace_until.is_none() => {
                    grace_until = Some(tokio::time::Instant::now() + self.config.shutdown_grace);
                }
                _ = tokio::time::sleep_until(grace_until.unwrap_or(far)), if grace_until.is_some() => {
                    return Execution::Abandoned;
                }
            }
        }
    }

    async fn beat(&self, job: &ClaimedJob, cancel: &CancellationToken) {
        match repo::heartbeat(&self.pool, job.id, &self.id).await {
            Ok(true) => {}
            Ok(false) => { warn!("Job was taken from this worker (reaped); cancelling its handler"); cancel.cancel(); }
            Err(err) => warn!(error = %err, "Heartbeat failed"),
        }
    }

    async fn record(&self, job: &ClaimedJob, result: Result<(), JobError>) {
        let outcome = outcome_for(job.attempts, job.backoff_seconds, result);
        let recorded = match &outcome {
            Outcome::Complete => repo::complete(&self.pool, job.id, &self.id).await,
            Outcome::Retry { delay, error } => repo::retry(&self.pool, job.id, &self.id, error, *delay).await,
            Outcome::Defer(delay) => repo::defer(&self.pool, job.id, &self.id, *delay).await,
            Outcome::Fail(error) => repo::fail(&self.pool, job.id, &self.id, error).await,
        };
        let terminal = matches!(outcome, Outcome::Fail(_))
            || (matches!(outcome, Outcome::Retry { .. }) && job.attempts >= job.max_attempts);
        match recorded {
            Ok(true) if terminal => error!(outcome = ?outcome, max_attempts = job.max_attempts, "Job failed permanently"),
            Ok(true) => debug!(outcome = ?outcome, "Job outcome recorded"),
            Ok(false) => warn!("Job was taken from this worker before its outcome was recorded"),
            Err(err) => warn!(error = %err, "Recording the job outcome failed; the reaper will reclaim it"),
        }
    }
}

pub(crate) fn outcome_for(attempt: i32, backoff_seconds: i32, result: Result<(), JobError>) -> Outcome {
    match result {
        Ok(()) => Outcome::Complete,
        Err(JobError::Retryable(e)) => Outcome::Retry { delay: backoff_delay(backoff_seconds, attempt), error: format!("{e:#}") },
        Err(JobError::Permanent(e)) => Outcome::Fail(format!("{e:#}")),
        Err(JobError::Unavailable(d)) => Outcome::Defer(d),
    }
}
```

```rust
/// Turns `NOTIFY jobs` into `wake.notify_waiters()`. On any listener error it
/// logs, waits `retry_after` and reconnects; workers keep polling meanwhile,
/// so a broken listener costs latency, never work.
pub(crate) async fn run(pool: PgPool, wake: Arc<Notify>, retry_after: Duration, shutdown: CancellationToken) {
    loop {
        tokio::select! {
            _ = shutdown.cancelled() => return,
            result = listen(&pool, &wake) => {
                let Err(err) = result;   // Ok is uninhabited
                warn!(error = %err, "Job LISTEN failed; workers fall back to polling");
            }
        }
        tokio::select! { _ = shutdown.cancelled() => return, _ = tokio::time::sleep(retry_after) => {} }
    }
}

/// Forwards notifications until the listener fails; never returns `Ok`.
async fn listen(pool: &PgPool, wake: &Notify) -> sqlx::Result<std::convert::Infallible> {
    let mut listener = JobNotifications::connect(pool).await?;
    loop {
        listener.next().await?;
        wake.notify_waiters();
    }
}
```

```rust
//! Session advisory locks for leader election.
//!
//! A session lock belongs to the connection that took it. Taken on a pooled
//! connection that later went back to the pool, it would stay held by
//! whichever caller borrowed that connection next — and never be released.
//! So the lock gets its own connection, detached from the pool
//! (`PoolConnection::detach`, sqlx 0.9: the pool opens a replacement), and
//! the lock lives exactly as long as that connection.

use sqlx::{Connection, PgConnection, PgPool};

pub struct LeaderLock { conn: PgConnection, key: i64 }

impl LeaderLock {
    pub async fn try_acquire(pool: &PgPool, key: i64) -> sqlx::Result<Option<Self>> {
        let mut conn = pool.acquire().await?.detach();
        let locked = sqlx::query_scalar!(r#"SELECT pg_try_advisory_lock($1) AS "locked!""#, key)
            .fetch_one(&mut conn).await?;
        if locked {
            Ok(Some(Self { conn, key }))
        } else {
            let _ = conn.close().await;
            Ok(None)
        }
    }

    pub async fn is_alive(&mut self) -> bool {
        self.conn.ping().await.is_ok()
    }

    pub async fn release(mut self) {
        let _ = sqlx::query_scalar!(r#"SELECT pg_advisory_unlock($1) AS "unlocked!""#, self.key)
            .fetch_one(&mut self.conn).await;
        let _ = self.conn.close().await;
    }
}
```

```rust
pub(crate) async fn run(pool: PgPool, services: AppServices, ticks: Vec<Tick>,
                        config: Arc<JobsConfig>, shutdown: CancellationToken) {
    if ticks.is_empty() { shutdown.cancelled().await; return; }
    loop {
        match LeaderLock::try_acquire(&pool, config.scheduler_lock_key).await {
            Ok(Some(mut lock)) => {
                info!("This instance is now the job scheduler leader");
                lead(&mut lock, &services, &ticks, &shutdown).await;
                lock.release().await;
                if shutdown.is_cancelled() { return; }
                warn!("Lost scheduler leadership; retrying");
            }
            Ok(None) => debug!("Another instance leads the scheduler"),
            Err(err) => warn!(error = %err, "Could not try the scheduler lock"),
        }
        tokio::select! {
            _ = shutdown.cancelled() => return,
            _ = tokio::time::sleep(config.leader_retry) => {}
        }
    }
}

/// Fires each tick at once, then every `tick.every`, while the lock's
/// connection is alive. Returns on shutdown or lost leadership.
async fn lead(lock: &mut LeaderLock, services: &AppServices, ticks: &[Tick], shutdown: &CancellationToken) {
    let start = tokio::time::Instant::now();
    let mut next: Vec<tokio::time::Instant> = vec![start; ticks.len()];
    loop {
        let due = next.iter().copied().min().unwrap_or(start);   // ticks is non-empty
        tokio::select! {
            _ = shutdown.cancelled() => return,
            _ = tokio::time::sleep_until(due) => {}
        }
        if !lock.is_alive().await { return; }
        let now = tokio::time::Instant::now();
        for (tick, at) in ticks.iter().zip(next.iter_mut()) {
            if *at > now { continue; }
            *at = now + tick.every;
            match (tick.fire)(services, Utc::now()).await {
                Ok(0) => {}
                Ok(n) => debug!(tick = tick.name, enqueued = n, "Scheduler tick"),
                Err(err) => warn!(tick = tick.name, error = %err, "Scheduler tick failed"),
            }
        }
    }
}
```

```rust
//! part of a sync session (the job handlers).
//!
//! The sync loop publishes each generation's client when that generation
//! starts and the guard clears it when `MatrixBot::run` returns by any path,

    fn default() -> Self { Self { cell: Arc::new(watch::channel(None).0) } }

    }
}

pub struct PublishedClient { cell: Arc<watch::Sender<Option<Client>>> }
impl Drop for PublishedClient {
    fn drop(&mut self) { self.cell.send_replace(None); }
```

```rust
    /// Enqueues a `reminder.fire` job for every pending reminder due by `now`.
    /// Idempotent: the dedupe key is `<id>:<trigger_at>` (R19).
    pub async fn enqueue_due(&self, now: DateTime<Utc>) -> Result<usize, AppError> {
        let due = repositories::reminders::get_due_reminders(&self.pool, now).await?;
        let mut enqueued = 0;
        for r in &due {
            let job = NewJob::reminder_fire(r.owner_id, r.id, r.trigger_at);
            if repositories::jobs::enqueue(&self.pool, &job).await?.is_some() { enqueued += 1; }
        }
        Ok(enqueued)
    }

    pub async fn complete_delivery(&self, reminder: &Reminder, now: DateTime<Utc>) -> Result<(), AppError> {
        // Published before advancing, as the loop did: the message is out.

        match next_occurrence(reminder.trigger_at, reminder.recurrence, now) {
            Some(next) => { repositories::reminders::reschedule(&self.pool, reminder.id, next).await?; }
            None => { repositories::reminders::mark_triggered(&self.pool, reminder.id).await?; }
        }
        Ok(())
    }
```

```rust
        }
    }
}

impl ReminderFireHandler {
    async fn failed_attempt(&self, reminder: &Reminder, ctx: &JobContext, reason: String) -> Result<(), JobError> {
        if ctx.is_last_attempt() {
            error!(reminder_id = reminder.id, attempts = ctx.attempt, "Reminder exhausted its delivery attempts; marking failed");
            self.services.reminders.mark_failed(reminder.id).await?;
            return Err(JobError::Permanent(anyhow::anyhow!(reason)));
        }
        if let Err(err) = self.services.reminders.record_failed_attempt(reminder, ctx.attempt).await {
            warn!(reminder_id = reminder.id, error = %err, "Could not mirror retry_count");
        }
        warn!(reminder_id = reminder.id, attempt = ctx.attempt, max = ctx.max_attempts, %reason, "Reminder delivery failed; will retry");
        Err(JobError::Retryable(anyhow::anyhow!(reason)))
    }
}
```

```rust
            let quote = match fetch_latest_price(&symbol).await {
                Ok(q) => q,
                Err(err) => { debug!(%symbol, %err, "No price for alert check"); continue; }
            };
            for alert in self.list_active_alerts_for_symbol(&symbol).await? {
                let price_minor = price_to_minor(quote.price, alert.currency_exponent);
                if !alert.parsed_condition().is_met(price_minor, alert.target_price_minor) { continue; }

                if self.mark_alert_triggered(&alert).await? {
                    triggered.push(TriggeredAlert { alert, price_minor });
                }
            }
        }
        Ok(triggered)
    }
```
